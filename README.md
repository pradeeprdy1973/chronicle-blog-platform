# ✨ The Chronicle

A modern full-stack blogging platform built with **React**, **Express.js**, and **SQLite**. Features secure authentication, rich content publishing, threaded discussions, likes, author profiles, and a responsive editorial experience.

## 🚀 Features

* 🔐 JWT Authentication & Authorization
* ✍️ Create, Edit & Delete Blog Posts
* 🖼️ Cover Images & Tag Support
* 💬 Threaded Comments & Replies
* ❤️ Like / Unlike Posts
* 👤 Author Profiles
* 🔍 Search, Filter & Pagination
* 📱 Fully Responsive Design

## 🛠️ Tech Stack

### Frontend

* React 18
* React Router v6
* Axios
* react-hot-toast
* date-fns

### Backend

* Node.js
* Express.js
* SQLite (better-sqlite3)
* JWT Authentication
* bcryptjs

## ⚡ Quick Start

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm start
```

Frontend: `http://localhost:3000`
Backend: `http://localhost:5000`
